# Documentación Funcional por Módulo

> Documentación orientada a usuarios finales que explica qué puede hacer cada módulo del sistema.

## Propósito

Esta carpeta contiene documentación no técnica de cada módulo de Amauta. Cada documento responde:

- **¿Qué puedo hacer?** - Funcionalidades disponibles por rol
- **¿Cómo accedo?** - Dónde encontrar cada funcionalidad
- **¿Qué necesito?** - Requisitos previos
- **¿Cómo funciona?** - Flujos paso a paso
