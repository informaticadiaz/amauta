# Issue #57 — F3-006: UI básica de crear evaluación

**Qué podés hacer ahora:** crear una evaluación básica asociada a uno de tus cursos desde el panel de educador.

---

## Educador, ahora podés:

### Crear una evaluación básica

1. Ingresá a https://amauta.diazignacio.ar/dashboard/evaluaciones
2. Hacé click en "Crear evaluación"
3. Completá título, curso asociado y parámetros opcionales
4. Guardá y confirmá el mensaje de éxito
