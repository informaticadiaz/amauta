# Issue #21 — Feature: Integración con NAP (Núcleos de Aprendizajes Prioritarios)

**Qué podés hacer ahora:** Crear y organizar cursos usando categorías alineadas a la currícula oficial argentina (NAP), con ejemplos por nivel educativo.

---

## Educadores, ahora podés:

### Crear un curso alineado a NAP

1. Entrá a https://amauta.diazignacio.ar/dashboard/cursos/nuevo
2. Elegí una **categoría NAP** (Matemáticas, Lengua y Literatura, Educación Física, etc.)
3. Completá el curso y guardalo

### Usar cursos de ejemplo por nivel

- Revisá cursos ya cargados en https://amauta.diazignacio.ar/cursos
- Usalos como referencia para preparar nuevos contenidos

---

## Administradores, ahora podés:

### Revisar las categorías curriculares

1. Entrá a https://amauta.diazignacio.ar/dashboard/categorias
2. Verificá que las áreas estén alineadas con los NAP
