# Issue #56 — F3-005: Endpoint crear evaluación (educador)

**Qué podés hacer ahora:** ya se pueden crear evaluaciones básicas asociadas a un curso desde el backend (la pantalla web se incorpora en el próximo paso).

---

## Educador, ahora podés:

### Crear una evaluación básica para un curso

1. Elegir un curso propio donde se quiera evaluar a estudiantes.
2. Definir título, descripción y reglas básicas (tiempo, puntaje mínimo, intentos).
3. La evaluación queda creada y lista para usarse cuando esté disponible la pantalla.
