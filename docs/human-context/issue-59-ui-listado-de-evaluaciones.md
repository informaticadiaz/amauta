# Issue #59 — F3-008: UI listado de evaluaciones (educador)

**Qué podés hacer ahora:** ver tus evaluaciones por curso y crear nuevas desde el dashboard.

---

## Educador, ahora podés:

### Ver evaluaciones por curso

1. Iniciá sesión en https://amauta.diazignacio.ar
2. Entrá a `Dashboard` → `Evaluaciones`
3. Elegí un curso y revisá el listado de evaluaciones disponibles

### Crear una evaluación nueva

- En la misma pantalla, usá el botón **Crear evaluación**
- Te lleva al formulario para cargar los datos básicos
