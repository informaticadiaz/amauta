## Educador, ahora podés:

### Ver el listado de evaluaciones de un curso

1. Seleccioná un curso propio desde la sección de gestión.
2. Consultá el listado de evaluaciones asociadas a ese curso.
3. Usá ese listado para decidir qué evaluación editar o revisar.
