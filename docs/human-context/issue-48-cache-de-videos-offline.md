# Issue #48 — F2-005: Cache de videos offline con Cache API

**Qué podés hacer ahora:** descargar cursos con lecciones de video y reproducir esos videos sin conexión.

---

## Estudiante, ahora podés:

### Descargar un curso con videos para usarlo offline

1. Entrá a un curso desde el catálogo: `https://amauta.diazignacio.ar/cursos/[slug-del-curso]`.
2. Tocá **"Descargar para offline"**.
3. Esperá a que finalice la descarga.

### Reproducir videos sin conexión

- Abrí el curso descargado desde la opción **"Abrir curso offline"**.
- Entrá a una lección de video y reproducila sin internet.
