# Issue #63 — F3-012: UI toggle publicar/despublicar evaluación

**Qué podés hacer ahora:** publicar o despublicar una evaluación desde su detalle en el dashboard.

---

## Educador, ahora podés:

### Cambiar el estado de una evaluación

1. Entrá a https://amauta.diazignacio.ar/dashboard/evaluaciones
2. Abrí una evaluación para ver su detalle
3. Usá el botón "Publicar" o "Despublicar" según el estado actual

### Ver el resultado del cambio

- Se muestra un mensaje de éxito o error.
- El estado cambia entre "Borrador" y "Publicada" en el mismo detalle.
