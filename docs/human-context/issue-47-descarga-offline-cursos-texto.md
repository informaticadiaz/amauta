# Issue #47 — Descarga offline de cursos (texto) + UI de progreso

**Qué podés hacer ahora:** descargar cursos de texto para estudiar sin conexión y eliminarlos cuando quieras.

---

## Estudiante, ahora podés:

### Descargar un curso para usarlo offline

1. Entrá al detalle de un curso desde https://amauta.diazignacio.ar/cursos
2. En la columna derecha, hacé clic en **"Descargar para offline"**
3. Esperá a que la barra llegue a 100%

### Abrir un curso sin conexión

1. Una vez descargado, hacé clic en **"Abrir curso offline"**
2. Accedé a las lecciones descargadas incluso sin internet

### Eliminar la descarga

- En el mismo panel, hacé clic en **"Eliminar descarga"** para liberar espacio
