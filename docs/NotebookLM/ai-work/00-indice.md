## Resumen Ejecutivo

### ¿Qué Aprenderás?

1. **Fundamentos**: Cómo funcionan los LLMs y qué esperar de ellos
2. **Contexto**: La clave para obtener respuestas precisas y útiles
3. **Prompting**: Técnicas para comunicarte efectivamente con IAs
4. **Skills**: Reutilizar instrucciones complejas como "comandos"
5. **Flujos**: Integrar IA en tu proceso de desarrollo
6. **Práctica**: Patrones probados para tareas comunes

### Principios Fundamentales

```
1. CONTEXTO ES TODO
   └── La IA solo sabe lo que le proporcionas

2. SER ESPECÍFICO
   └── Instrucciones vagas = resultados vagos

3. ITERAR
   └── Refinar respuestas es parte del proceso

4. VERIFICAR
   └── La IA puede equivocarse, siempre revisar

5. DOCUMENTAR
   └── Lo que funciona hoy, reutilizarlo mañana
```

## Glosario Rápido

| Término         | Definición                                             |
| --------------- | ------------------------------------------------------ |
| **LLM**         | Large Language Model - Modelo de lenguaje grande       |
| **Prompt**      | Instrucción o pregunta enviada a la IA                 |
| **Contexto**    | Información que la IA usa para responder               |
| **Token**       | Unidad de texto (~4 caracteres)                        |
| **Skill**       | Instrucción reutilizable para tareas específicas       |
| **Agente**      | IA que puede ejecutar acciones autónomamente           |
| **RAG**         | Retrieval Augmented Generation - Búsqueda + Generación |
| **Fine-tuning** | Entrenamiento adicional de un modelo                   |
