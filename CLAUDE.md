# Contexto de Amauta para Claude Code

Este archivo se conserva únicamente por compatibilidad con herramientas heredadas.
No es una fuente de verdad y no contiene reglas, estado ni planificación propios.

Consultar las fuentes canónicas del workspace en este orden:

1. `AGENTS.md` — reglas permanentes y límites de desarrollo.
2. `CODEX_STATE.md` — continuidad operativa actual.
3. `README.md` — visión y principios del proyecto.
4. `docs/project-management/roadmap.md` — fase, sprint y estado del producto.
5. `WORKFLOW.md` — proceso de trabajo con issues.
6. `docs/ai-context/` — patrones y contexto técnico específico.

Para datos y Prisma, verificar siempre `apps/api/prisma/schema.prisma` y las reglas
indicadas en `AGENTS.md`. No inferir el estado de una funcionalidad desde este
archivo.
