T5 — Contrato compartido mínimo de búsqueda
Fecha: 2026-11-12
Repositorio: /home/ignacio/amauta

Decisión
- `@amauta/types` es la fuente canónica de los tipos wire estabilizados del catálogo: parámetros de búsqueda, curso de catálogo y respuesta paginada.
- `@amauta/shared` es la fuente canónica de la validación Zod de `GET /cursos/buscar`.
- No se exponen tipos generados por Prisma ni se generaliza el contrato a otros módulos todavía.

Implementación
- Se agregaron `BusquedaCursosParams`, `CursoCatalogo` y `ListaCursosResponse` en `packages/types/index.ts`.
- Se trasladó `busquedaCursosSchema` a `packages/shared/index.ts` y el DTO del API ahora lo reexporta.
- El controller y el service de cursos consumen `ListaCursosResponse` desde `@amauta/types`.
- La página pública de catálogo consume `ListaCursosResponse` y `CursoCatalogo` desde `@amauta/types`.
- Se eliminaron las interfaces duplicadas del catálogo web.
- El API resuelve los paquetes compartidos compilados (`packages/*/dist`) para respetar su `rootDir`.
- Se actualizaron `main`/`types` de los paquetes y el lockfile para reflejar sus artefactos compilados y dependencias.
